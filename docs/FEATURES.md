## 0. 入口一览

| 入口 | 触发方式 | 说明 |
|---|---|---|
| 看一眼 | `F8` / 点桌宠 / 右键菜单 | 看前台窗口、选中文字或整块桌面 |
| 看一眼并提问 | `F7` / 双击桌宠 / 右键菜单 | 先问一句，再带着问题看 |
| 看几眼（多画面） | `F9` / 右键菜单 | 开始收集，多次 F8 累加，结束一起看 |
| 陪伴记录 | 侧边栏「陪伴记录」/ 右键菜单 | 历史记录、追问、开新会话 |
| 设置 | DSH 设置 → 陪伴桌宠 | 人设、提示词、桌宠、热键 |
| Agent 工具 | 对话里调用 | 6 个工具，见第 7 节 |

热键默认 `F8 / F7 / F9`，都能在设置页里按键盘录制改成别的。

---

## 1. 看一眼（F8）

- **目标判定**：前台窗口优先；有选中文字时优先文字（比截图便宜也更准）；没有可看的窗口时退回「桌面」。
- **桌面模式**：把**所有显示器各截一张**一起给模型，按「屏幕 N」标注，不猜用户在看哪块屏。
- **选中文字**：两轮焦点读 + 交叉验证；Obsidian 这类会把「光标所在行」当成选区的应用会被否决，退回截图。
- **多屏一致**：点桌宠和按热键走同一段采集代码，不会出现两种结果。
- **模型调用**：系统提示 = 人设 → 规则；输出长度按「信息密度」档位。
- **落盘与说话**：先写记录（拿到 id）再让桌宠说话，点气泡能定位到那条记录。
- 代码：`lib/look.js`（采集 / 调模型）、`lib/native.js`（桥）、`lib/buddy.js`（气泡）。

## 2. 看一眼并提问（F7）

- 与 F8 同一条流水线，只是抓取前后先弹一个**自绘多行输入面板**（贴在人物上方，跟随拖动，`Esc` 取消）。
- 取消 = 不花钱、不留记录；空输入按 F8 处理。
- 记录里带 `question`，面板和追问都看得到。

## 3. 多画面收集（F9）

- `F9` 开始 → 每次 `F8` 加一张（截完就存缩略图 + 后台 OCR，**不调模型**）→ 结束一起看。
- 常驻气泡显示「● 多画面 · 已收 N 张」，三个按钮：**结束并看 / 提问 / 取消**。
- 「提问」与 `F7` 完全同路径：问一句 → 带问题结束这一组 → 分析 → 写一条 `kind: multi` 记录。
- 超过 9 张会分页（map-reduce：逐页小结 → 合成），单次请求不会被图片撑爆。

## 4. 桌宠浮窗（自绘，`buddy/Buddy.swift`）

- 静态立绘 + 气泡 + 右键菜单，一个原生 AppKit 进程；不依赖 `dsh-pet`。
- **拖动**自由，位置记在 `buddy.state.json`；「重置位置」回主屏右下角。
- **气泡**支持：普通 / 紧凑单行 / 粗体 / 常驻（`sticky`）/ 带动作按钮 / `{hide:true}` 主动收起。
- **右键菜单**（两栏）：
  上半栏「看一眼 / 看一眼并提问 / 看几眼 / 看一阵」，下半栏「陪伴记录 / 隐藏 / 退出桌宠」。
- **启动问候**：第一次拉起 1.2 秒后说「我在这儿」（崩溃退避重启不重复），顺便让你知道它落哪块屏。
- **重启不重放**：启动时把已存在的命令文件标记为「已读」，不会把上一条回复再念一遍。

## 4.5 看一阵（v1）

- 入口：右键菜单「看一阵」、命令 `/companion watch`（停止 `/companion watch-stop`）；内部能力 `watch-window:<id>` 锁指定窗口。
- **先确认再开始**：点「看一阵」先弹录制气泡（第一行 `● 看一阵 · 应用名「标题」`、第二行 `0:00 · 0 段 · 0 帧 · 0 token`），
  第一个按钮是「开始」；按下去才真正采集，按钮变「暂停」，暂停后变「继续」。
- **开始前跟随活动窗口**：气泡里的应用名会随你切换应用实时更新（系统激活通知驱动，不轮询）；
  **按「开始」那一刻重新取一次前台并锁定**，之后切窗口不再变。同一应用内换窗口不触发激活事件，
  气泡名字可能滞后，但锁定目标不受影响。
- 目标锁死：窗口触发就锁这个窗口（被遮挡也抓它自己）；桌面背景则锁光标所在那块屏。
- 采样：**1 / 2 / 5 / 10 / 20 秒**，点气泡上的「Ns」展开菜单直接选（不是循环切换），下一拍生效；默认 2 秒。
- 变速窗口：10s → 15s → 30s（首段短，先给一次反馈）。
- 判变（三路取或）：整帧平均差（自适应基线 = 近 20 次中位数 ×3）/ 变化像素占比 ≥1% / 8×8 块最大差 ≥6%；
  缩略帧 128×72、保持比例补黑边；窗口尺寸变化单独记录并强制留一帧。
- 留存：变化帧 + **60 秒锚点帧**；每段最多 24 帧；窗口画面完全不变时记「空档段」，时间线不断档。
- 分析：**文本路径 12 帧**（OCR 行级去重，只喂新行）、**图片路径 9 帧**；
  出图条件：文字不足 / 模型标 `[需要画面]` / 高动态（块差 ≥0.10 **且**变化面积 ≥5%，60 秒节流）。
- 控制条：两行（状态+应用名 / 时长·段数·帧数·token），按钮：开始/暂停/继续 · 停止 · 丢弃 · 采样率 · 段▸。
  token 单位按量级自适应（k → M），暂停期间不计时。
- 记录：`kind: watch` + `timeline`（每段起止、摘要、字数、是否看图、原因、拼图、空档）+ `stats`
  （帧/锚点/跳过/空档/拼图/窗口缩放/花费估算/三路信号分位数）；面板里每段有「画面」按钮看拼图。
- 开新会话：`recordImagePaths()` 统一取图——看一阵按段带上全部拼图（≤9 张）。
- 性能：OCR 在采样间隙预取（并发 2，只预取前 12 帧），停止从 ~10s 降到 1–2s。

## 5. 陪伴记录面板（`lib/client.js`）

- **顶部冻结区**：搜索框、`共 N 条 · 当前范围缓存 X（全部 Y）`、工作区选择、多选操作，向下翻列表时不动。
- **搜索**：标题 / 画面文字（OCR）/ 问题 / 回答；**范围**：今天 / 7 天 / 30 天 / 全部（按本地时区切）。
- **卡片**：时间 + 应用与标题、当时的评语；点击标题展开讨论线程。
- **多画面卡片**：主缩略图 + `+N` 角标；展开后 3 列宫格**独占整行**（不挤压右侧文字）。
- **大图层**：两侧半透明 `‹ ›` 切换、底部 `3 / 5` 计数、`←`/`→` 切图、`Esc` 关闭；原图地址带 `index`（曾经点第三张看第一张）。
- **追问**：每轮把「抓取内容 + 当时的评语 + 图（≤9 张）+ OCR 文字」重新发一遍（模型没有跨调用记忆），
  带 usage 与缓存命中率；`reuseImage=first` 可只在首轮带图。
- **开新会话**：选工作区与 agent preset，把记录变成一条真实会话的首条消息（多画面最多带 9 张原图）；多选后可以「为选中记录建会话」。
- **删除**：单条删除、右键多选批量删除、按范围清理（整条 / 只删图）。
- **容量**：范围容量 = 记录引用的图片字节和；「全部」= 磁盘实际占用（含 `history.jsonl`）。孤儿图片启动时清一次。

## 6. 设置页（DSH 设置 → 陪伴桌宠）

| 区块 | 内容 |
|---|---|
| 权限 | 屏幕录制 / 辅助功能 / 自动化状态；「请求授权」触发系统框，「打开设置」直达对应面板，「刷新状态」只查询 |
| 人设 | 自由文本，存 `~/.dsh/dsh-companion-journal/persona.md`；只影响语气称呼 |
| 提示词 | 规则段全文可编辑（含密度那一行）+ 密度下拉（改写第 4 行）+「重置为标准模板」+ 最终拼装预览 |
| 追问规则 | 「接着问」用的系统提示 |
| 显示桌宠 | 开关浮窗（关掉后热键照常可用） |
| 立绘 / 尺寸 / 字号 | 原生选图或目录浏览；尺寸 64–512、字号 10–24 |
| 快捷键 | 三个热键，点框后按键录制，`Esc` 取消 |
| 重置位置 | 让人物回主屏右下角 |

提示词覆盖存 `~/.dsh/dsh-companion-journal/prompt.json`；与内置模板一致时不写文件，所以以后改默认模板能自动跟上。

## 10. 运行约束与健壮性

- **事件驱动优先**：浮窗命令用目录事件（`DispatchSource`）+ 5 秒兜底；页面用 SSE；空闲时 0 定时器 / 0 轮询。
- **命令文件必须原子写**（临时文件 + `rename`），否则监听方收不到事件。
- **异步必须有兜底**：`finishCollection` / `runLook` 等 fire-and-forget 路径都自带 `.catch`，否则一次 rejection 能把整个宿主带崩（v0.40.2 真发生过）。
- **推理吃光 token**：预算 4000（合成 6000 / 追问 8000），空正文 + 有推理时自动翻倍重试一次。
- **客户端过期提示**：客户端上报 `CLIENT_VERSION`，与宿主不一致时在头顶挂常驻气泡「有新版本，重启客户端生效」。
- **多通道**：打开面板同时有 SSE 与「窗口获得焦点时查 pending」两条路，断一条不影响。

## 12. 已知边界（未做）

- **看一阵没有音频**：只有窗口像素 + OCR；音频方案见 [AUDIO-DESIGN.md](AUDIO-DESIGN.md)。
- **看一阵读不到视频播放进度**：时间轴是录制墙钟，视频暂停/缓冲会错开。
- **拼图**：行高与列宽按信息量，但还没做逐格 1/k 档位与完整 DP 打包。
- **长会话**：没有会话目录上限与异常退出残留清理。

- 气泡与人物在同一个窗口：贴边出气泡会轻推一下；长气泡会把人物顶上去。方案见 ROADMAP。
- 追问 / 开新会话最多带 9 张图；更多只在提示里写张数。
- 浏览器正文需要扩展桥（未实现），目前只有标题。
- 「看一阵」只完成离线实验，v1 未实现。
- 面板 Markdown 渲染、记录 ↔ 会话关联：暂缓。
